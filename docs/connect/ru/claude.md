# Плагин Quotalogic для Claude

[English](../en/claude.md) · **Русский** · [中文](../cn/claude.md)

## Что это и зачем

Плагин учит Claude работать с Quotalogic «по-человечески»: загрузить прайс-лист в каталог, поправить цены, показать цены в другой валюте, собрать и отправить коммерческое предложение. Claude сам понимает, когда плагин нужен, и всегда показывает, что собирается сделать, а записывает только после вашего «да».

Плагин сам добавляет подключение к Quotalogic. После установки нужно один раз войти в свой аккаунт Quotalogic — шаги ниже. Отдельно подключать Quotalogic не нужно.

## Как выбрать свой путь

Ответьте на два вопроса.

**1. Где вы работаете в Claude?**

- **Code** — программа `claude` в терминале или вкладка **Code** в приложении Claude Desktop. Путь описан в части 1.
- **Чат или Cowork** — сайт claude.ai или вкладка «Чат» в приложении Claude Desktop. Путь описан в части 2.

**2. Какая у вас подписка?**

- **Личная** (Pro, Max): вы всё делаете сами.
- **Корпоративная** (Team, Enterprise): в чате и Cowork плагин обычно подключает владелец организации (часть 3), а вы только устанавливаете или находите его у себя.
- **Free**: плагины на этом тарифе поставить нельзя (подтверждено на практике). Нужна платная подписка: Pro, Max, Team или Enterprise.

| Где работаете                 | Личная подписка         | Корпоративная подписка                                                          |
| ----------------------------- | ----------------------- | ------------------------------------------------------------------------------- |
| Code (терминал, вкладка Code) | часть 1: способ А или Б | часть 1, либо владелец организации раздаёт плагин всем (часть 3)                |
| Чат и Cowork                  | часть 2                 | часть 3 (владелец организации), потом вы устанавливаете у себя (часть 2, шаг 3) |

**Что описано по документации Anthropic и у нас не проверено руками:** всё про чат, Cowork и настройки организации (части 2 и 3), названия их меню. В терминале (часть 1) проверены установка, в том числе из архива, и то, что подключение из плагина появляется в `/mcp` с пометкой «нужен вход». Сам вход в подключение из плагина ещё не проходили.

## Что понадобится

1. **Аккаунт Quotalogic.** Подключение плагин добавит сам. Если вы раньше уже подключали Quotalogic вручную, ничего не меняйте: Claude оставит одно подключение.
2. **Сам плагин**, одним из способов:
   - **Из архива.** Мы присылаем файл. Доступ к GitHub не нужен (кроме варианта «владелец организации синхронизирует из GitHub»).
   - **Из GitHub.** Нужен доступ к закрытому репозиторию `intergalactic-planb/plugins`.

Если не уверены, берите архив: он проще. Мы можем прислать два файла: `quotalogic-plugins.zip` (для части 1) и `quotalogic-plugin-claude.zip` (для частей 2 и 3). Они отличаются раскладкой внутри, поэтому один файл на оба случая не подходит.

## Часть 1. Code (терминал и вкладка Code)

Проверка, что Claude установлен (терминал):

```bash
claude --version
```

### Способ Б — из архива (проще)

1. Распакуйте `quotalogic-plugins.zip` в постоянное место, например в папку `Документы`. Получится папка `quotalogic-plugins`.
   **Не удаляйте и не переносите её после установки** — Claude читает плагин оттуда.
2. Откройте терминал и подключите папку, указав путь к ней (пример для macOS):

   ```bash
   claude plugin marketplace add ~/Documents/quotalogic-plugins
   ```

   Должно появиться: `Successfully added marketplace: quotalogic-plugins`.

3. Установите плагин:

   ```bash
   claude plugin install quotalogic@quotalogic-plugins
   ```

   Должно появиться: `Successfully installed plugin: quotalogic@quotalogic-plugins`.

**Важно:** архив — снимок на день отправки. Если мы потом улучшим плагин, у вас останется старая версия, пока вы не получите новый архив.

### Способ А — из GitHub

1. **Доступ к репозиторию.** Откройте https://github.com/intergalactic-planb/plugins. Страница открылась — доступ есть. Ошибка 404 — доступа нет: напишите нам, мы его выдадим, либо используйте архив.
2. **Вход в GitHub на компьютере.** В терминале:

   ```bash
   gh auth login
   gh auth setup-git
   ```

   В первой команде выберите GitHub.com → HTTPS → войдите через браузер. Проверка: `gh auth status` показывает `Logged in to github.com`.

3. Подключите каталог плагинов (один раз на компьютер):

   ```bash
   claude plugin marketplace add intergalactic-planb/plugins
   ```

4. Установите плагин:

   ```bash
   claude plugin install quotalogic@quotalogic-plugins
   ```

**Вкладка Code в приложении Claude Desktop** читает те же настройки, что и терминал: поставили плагин в терминале — он уже есть и в приложении. Подключить каталог плагинов (шаг 3) в приложении нельзя, это делается в терминале; после этого плагин можно ставить кнопками: **+** у поля ввода → **Add plugins**.

### Войти в Quotalogic

Один раз после установки.

1. Создайте отдельную пустую папку и откройте Claude в ней. Не запускайте Claude в папке с кодом или секретами.

   ```bash
   mkdir -p ~/quotalogic && cd ~/quotalogic && claude
   ```

   Если Claude был открыт во время установки, выйдите (`/exit`) и запустите снова.
2. Наберите `/mcp` и выберите `plugin:quotalogic:quotalogic` → **Authenticate**.
3. Откроется браузер: войдите в Quotalogic, проверьте рабочее пространство и нажмите **Разрешить**.
4. В `/mcp` у подключения статус **connected**.

Агент работает в том рабочем пространстве, которое было открыто в браузере в момент «Разрешить». Нужно другое — переключитесь в браузере и снова **Authenticate**. Вход держится до 30 дней без использования.

### Проверить, что работает

1. Спросите «Покажи мои каталоги Quotalogic» — должен прийти список из вашего рабочего пространства.
2. Наберите `/`. В списке должны быть четыре строки, начинающиеся с `/quotalogic:`: `catalog-import`, `catalog-edit`, `currency-conversion`, `offer`.
3. Положите в папку небольшой прайс и напишите обычными словами: «Создай каталог из файла prices.xlsx». Claude покажет, как понял колонки и валюту, и будет ждать вашего «да». Пока вы не ответили «да», ничего не записывается.

### Обновить

- **Способ А:**

  ```bash
  claude plugin update quotalogic@quotalogic-plugins
  ```

  Новая версия появится при следующем запуске Claude. Автообновление: в Claude наберите `/plugin` → вкладка **Marketplaces** → `quotalogic-plugins` → **Enable auto-update**. Для закрытого репозитория оно работает только если выполнен шаг 2 (`gh auth login` и `gh auth setup-git`): одна переменная с токеном не помогает. Если вход не сохранён, обновление молча не происходит и остаётся старая версия.
  Claude проверяет обновления сам не сразу: примерно через 10 минут после первого сообщения в сессии. Применяется после `/reload-plugins` или при следующем запуске.

- **Способ Б:** автоматически ничего не обновится. Получив новый архив, удалите плагин и папку (см. «Удалить»), распакуйте новый архив и повторите установку.

**Как сделать, чтобы обновления доходили без напоминаний:** отдельному клиенту нужно один раз включить автообновление (способ А). Организации это можно включить всем сразу — см. часть 3. Новая версия плагина доходит только когда мы повышаем номер версии: об этом заботимся мы.

### Удалить

```bash
claude plugin uninstall quotalogic@quotalogic-plugins
claude plugin marketplace remove quotalogic-plugins
```

Вместе с плагином из Claude уходит и подключение. Разрешение в самом Quotalogic остаётся — отозвать его можно в Quotalogic, раздел «Мои подключения». Если ставили из архива, после этого можно удалить папку `quotalogic-plugins`.

## Часть 2. Чат и Cowork (claude.ai и вкладка «Чат» в приложении)

Работает на личных подписках. Если у вас Team или Enterprise, сначала посмотрите часть 3: возможно, плагин уже подключён владельцем организации, или загрузка отключена правилами организации.

### Способ Б — загрузить архив

1. Нам нужен файл `quotalogic-plugin-claude.zip` (внутри сразу `.claude-plugin`, без внешней папки).
2. В Claude откройте **Customize → Plugins**, нажмите **Add → Upload plugin** и выберите файл. Допустимый размер — до 200 МБ.
3. Плагин появится в списке, включите его.
4. Подключите Quotalogic (см. «Войти в Quotalogic» ниже).

### Способ А — из GitHub

1. В **Customize → Plugins** нажмите **Add → Add marketplace**.
2. Введите `intergalactic-planb/plugins`.
3. Когда Claude попросит, подключите свой GitHub-аккаунт и дайте приложению Claude GitHub доступ к этому репозиторию. Нужен аккаунт с доступом к репозиторию.
4. Найдите `quotalogic` и установите.
5. Подключите Quotalogic (см. «Войти в Quotalogic» ниже).

### Войти в Quotalogic

В чате и Cowork подключение из плагина само не включается.

1. Откройте плагин в **Customize → Plugins** и вкладку **Connectors**.
2. Нажмите **Connect** у Quotalogic, войдите в Quotalogic и нажмите **Разрешить**.
3. На Team и Enterprise кнопка появится после того, как владелец организации добавит это подключение (часть 3).

Если Quotalogic уже был подключён в **Settings → Connectors**, второй раз подключать не нужно.

### Если у вас корпоративная подписка

Плагин может быть уже у вас: он в списке в **Customize → Plugins**. Если его нет, а **Add** ничего не предлагает, загрузку отключила организация, обратитесь к владельцу (часть 3).

### Проверить

В новом чате напишите: «Создай каталог из этого файла» и приложите небольшой прайс. Claude должен показать, как понял колонки, и дождаться «да». Если он говорит, что инструментов Quotalogic нет, не выполнен вход: шаги «Войти в Quotalogic» этой части.

## Часть 3. Владелец организации (Team и Enterprise)

Плагин раздаёт **владелец организации** (роль Owner). Обычный сотрудник этого сделать не может.

### Для чата и Cowork

1. Откройте **Organization settings → Plugins & skills** и нажмите **Add**.
2. Выберите один из вариантов:
   - **Upload plugin** — загрузить `quotalogic-plugin-claude.zip` (без GitHub, подходит для теста).
   - **Sync from GitHub** — подключить репозиторий `intergalactic-planb/plugins`. Репозиторий должен быть закрытым или внутренним (наш закрытый — подходит). Обновление идёт через подключение организации к GitHub, личные входы сотрудников не нужны. Синхронизация запускается кнопкой **Re-sync** или сама при изменении главной ветки, если включить **Sync automatically** (нужен webhook, это настройка GitHub).
3. Выберите **Default access** — кому плагин доступен:
   - **Not available** — никому;
   - **Available to install** — каждый ставит сам;
   - **Installed by default** — стоит у всех, но можно удалить;
   - **Required** — стоит у всех, убрать нельзя.
     На Enterprise можно выдать плагин отдельным группам пользователей.
4. Добавьте для организации подключение Quotalogic из плагина (на его вкладке **Connectors**). После этого каждый сотрудник подключает его своим аккаунтом Quotalogic.
5. Чтобы сотрудники не добавляли свои плагины, на вкладке **Policy** отключите **User-created skills**. Если отключить сам **Skills**, не будут работать никакие плагины организации.

### Для Code (терминал и вкладка Code)

Раздать плагин всем можно в **Organization settings → Claude Code → Managed settings**: добавляется каталог плагинов и включается плагин. Это настройки для технических специалистов, точный формат — в документации Anthropic про организационные плагины (`code.claude.com/docs/en/plugins/org.md`). Каждому сотруднику нужен доступ на чтение закрытого репозитория, либо используйте вариант с архивом. Плагин появится в начале следующей сессии Claude.

Чтобы плагин обновлялся у всех сам, добавьте в тот же блок `"autoUpdate": true` у каталога. Тогда сотрудник не сможет выключить автообновление:

```json
{
  "extraKnownMarketplaces": {
    "quotalogic-plugins": {
      "source": { "source": "github", "repo": "intergalactic-planb/plugins" },
      "autoUpdate": true
    }
  },
  "enabledPlugins": { "quotalogic@quotalogic-plugins": true }
}
```

Формат взят из документации Anthropic (`org.md`), у нас не проверялся.

Организация может и запретить сотрудникам добавлять свои каталоги плагинов (настройка `strictKnownMarketplaces`). Тогда способы А и Б из части 1 у них не сработают, обратитесь к владельцу.

## Если не работает

| Что видите                                                 | Что делать                                                                                                                                                          |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Repository not found` или ошибка доступа (способ А)       | Нет доступа к репозиторию или не выполнен вход в GitHub: шаг 1 и 2 способа А. Или возьмите архив                                                                    |
| `Plugin "quotalogic" not found in marketplace`             | Опечатка. Команда должна быть именно `quotalogic@quotalogic-plugins`                                                                                                |
| Способ Б: «путь не найден»                                 | Проверьте, что папка на месте и путь в команде верный                                                                                                               |
| После `/` нет строк `/quotalogic:`                         | Перезапустите Claude или наберите `/reload-plugins`. Ошибки видны в `/plugin` → вкладка **Errors**                                                                  |
| Claude говорит, что инструментов Quotalogic нет            | Не выполнен вход: в Code — «Войти в Quotalogic» части 1, в чате — части 2. В `/mcp` должен быть статус **connected**                                                  |
| В чате нет **Add** или **Upload plugin**                   | Загрузку отключила организация или тариф не позволяет: обратитесь к владельцу организации                                                                           |
| Загрузка архива в чате не принимается                      | В корне архива должна лежать папка `.claude-plugin` (без внешней папки) и в корне не должно быть папки `bin` с программами. Возьмите `quotalogic-plugin-claude.zip` |
| В Code `/plugin` не открывается или каталог не добавляется | Организация запретила сотрудникам свои каталоги: обратитесь к владельцу                                                                                             |

## Для тех, кто собирает и тестирует

**Два архива из клона `../plugins`** (нужен доступ к репозиторию; берётся то, что закоммичено в `main`):

1. `quotalogic-plugins.zip` — для части 1 (терминал, вкладка Code) и для Codex. Команды сборки, с подменой одного файла для Codex, — в [инструкции Codex](codex-chatgpt.md#для-тех-кто-собирает-и-тестирует). Для Claude эта подмена ничего не меняет.
2. `quotalogic-plugin-claude.zip` — для частей 2 и 3 (чат, Cowork, загрузка владельцем). Содержимое должно лежать в корне архива, без внешней папки:

   ```bash
   git -C ~/Projects/plugins archive --format=zip main -o ~/quotalogic-plugin-claude.zip
   ```

Требования к такому архиву взяты из документации Anthropic: один `.claude-plugin/plugin.json` в корне, лимит 200 МБ, папки `bin` с программами в плагине быть не должно (в нашем плагине её нет). **Загрузка нашего архива в claude.ai и в настройки организации нами не проверялась**: возможно, придётся подправить раскладку. Для скиллов в чате и Cowork отдельных ограничений документация не называет.

Версию плагина (в `.claude-plugin/plugin.json`) лучше указать в сообщении клиенту, чтобы было понятно, что он получил.

**Проверить как пользователь, не трогая свои настройки** (для части 1) — поставить только в тестовую папку:

```bash
mkdir -p ~/quotalogic-plugin-test && cd ~/quotalogic-plugin-test
claude plugin marketplace add intergalactic-planb/plugins --scope local
claude plugin install quotalogic@quotalogic-plugins --scope local
```

Настройки запишутся в `.claude/settings.local.json` этой папки. Проверить ещё не запушенную версию: вместо `intergalactic-planb/plugins` указать путь к клону, например `~/Projects/plugins`. Убрать — удалить тестовую папку.
