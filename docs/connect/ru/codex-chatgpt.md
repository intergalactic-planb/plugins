# Плагин Quotalogic для Codex и ChatGPT

[English](../en/codex-chatgpt.md) · **Русский** · [中文](../cn/codex-chatgpt.md)

## Что это и зачем

Плагин помогает загрузить прайс-лист, поправить цены, показать их в другой валюте или собрать коммерческое предложение. Перед импортом помощник показывает, что собирается загрузить, и ждёт отдельного подтверждения. Для некоторых действий, например создания коммерческого предложения, достаточно вашей прямой просьбы.

В Codex плагин сам добавляет подключение к Quotalogic: после установки нужно один раз войти в свой аккаунт. В ChatGPT через браузер подключение пока настраивается отдельно.

## Что понадобится

1. **Аккаунт Quotalogic.** В Codex подключение добавит сам плагин, отдельно его подключать не нужно. В ChatGPT через браузер подключите Quotalogic отдельным приложением.
2. **Плагин со сценариями.** Для Codex без доступа к GitHub попросите у команды Quotalogic готовый файл `quotalogic-plugins.zip`. Если у вас есть доступ к закрытому репозиторию, можно установить плагин из GitHub. В ChatGPT через браузер плагин для команды подключает администратор.

## Codex на компьютере

Для установки плагина по этой инструкции понадобится терминал. Выполните `codex --version`. Если команда не найдена, установите Codex для терминала. [Инструкция OpenAI](https://learn.chatgpt.com/docs/cli)

### Установка из архива без GitHub

1. Распакуйте полученный от команды файл `quotalogic-plugins.zip` в постоянное место, например в папку `Документы`. Получится папка `quotalogic-plugins`.
   **Не удаляйте и не переносите её после установки.**
2. Подключите папку командой ниже. В примере указан путь к папке «Документы» на macOS. Если вы распаковали архив в другое место, подставьте путь к своей папке.

   ```bash
   codex plugin marketplace add ~/Documents/quotalogic-plugins
   ```

3. Установите плагин.

   ```bash
   codex plugin add quotalogic@quotalogic-plugins
   ```

4. Перейдите к разделу «Проверить, что работает».

Для обновления понадобится новый архив от команды Quotalogic.

### Установка из GitHub

1. Войдите в GitHub в браузере и откройте [репозиторий плагина](https://github.com/intergalactic-planb/plugins). Если видите ошибку 404, попросите у команды Quotalogic доступ или готовый архив.
2. Войдите в GitHub из терминала. Чтобы выполнить команды, понадобится [GitHub CLI](https://cli.github.com/).

   ```bash
   gh auth login
   gh auth setup-git
   ```

   В первой команде выберите **GitHub.com → HTTPS** и войдите через браузер под аккаунтом с доступом к репозиторию. Вторая команда позволяет Git использовать этот вход. Команда `gh auth status` покажет, под каким аккаунтом вы вошли.

3. Подключите каталог плагинов.

   ```bash
   codex plugin marketplace add intergalactic-planb/plugins
   ```

4. Установите плагин.

   ```bash
   codex plugin add quotalogic@quotalogic-plugins
   ```

### Войти в Quotalogic

Один раз после установки, в терминале:

```bash
codex mcp login quotalogic
```

Откроется браузер: войдите в Quotalogic, проверьте рабочее пространство и нажмите **Разрешить**. В терминале появится `Successfully logged in to MCP server 'quotalogic'`.

Агент работает в том рабочем пространстве, которое было открыто в браузере в момент «Разрешить». Нужно другое — переключитесь в браузере и повторите команду.

**Если вы раньше подключали Quotalogic вручную** командой `codex mcp add`, у вас окажутся два одинаковых подключения. Посмотрите имя ручного в `codex mcp list` (любое, кроме `quotalogic`) и удалите его, подставив это имя:

```bash
codex mcp remove <имя>
```

Проверка: `codex mcp list` показывает одну строку `quotalogic` с адресом Quotalogic.

### Проверить, что работает

1. Проверьте, что плагин установлен.

   ```bash
   codex plugin list --marketplace quotalogic-plugins
   ```

   В строке `quotalogic@quotalogic-plugins` должно быть `installed, enabled`.

2. Откройте **новый** чат Codex в отдельной папке. Если пользуетесь приложением ChatGPT, сначала перезапустите его и выберите **Codex**.
3. Наберите `$` и выберите сценарий импорта `quotalogic:catalog-import`.
4. Положите в папку небольшой тестовый прайс и напишите «Подготовь импорт этого прайса в новый каталог Quotalogic и покажи предпросмотр. Остановись до запуска импорта». На предпросмотре должны быть колонки и валюта. На этом проверка заканчивается.

В обычной работе можно описать задачу своими словами. Помощник может подобрать сценарий сам.

### Обновить

- Если ставили из **GitHub**, выполните команды ниже.

  ```bash
  codex plugin marketplace upgrade quotalogic-plugins
  codex plugin remove quotalogic@quotalogic-plugins
  codex plugin add quotalogic@quotalogic-plugins
  ```

- Если ставили **из архива**, попросите новый файл. Удалите старую версию по инструкции ниже, распакуйте новый архив и повторите установку.

Уже открытый чат новую версию не получит — начните новый.

**Само не обновится.** В Codex и в приложении ChatGPT автообновления плагина нет: по документации OpenAI каталог обновляется только командой `codex plugin marketplace upgrade`. Поэтому о новых версиях мы сообщаем отдельно. Исключение — ChatGPT web, где каталог подключён администратором: он обновляется сам раз в день (см. «Обновить в ChatGPT web»).

### Удалить

```bash
codex plugin remove quotalogic@quotalogic-plugins
codex plugin marketplace remove quotalogic-plugins
```

Проверьте `codex mcp list`: подключения `quotalogic` там быть не должно. Разрешение в самом Quotalogic остаётся — отозвать его можно в Quotalogic, раздел «Мои подключения». Если ставили из архива, после этого можно удалить папку `quotalogic-plugins`.

## ChatGPT web

**Доступ к каталогам через браузер пока не подтверждён.** Перед проверкой сценариев отдельно подключите приложение Quotalogic и проверьте, что ChatGPT видит ваши каталоги. Работает ли в браузере подключение из самого плагина, тоже не подтверждено.

Если вы сотрудник, попросите администратора вашего рабочего пространства ChatGPT подключить плагин и предоставить вам доступ. Для установки уже добавленного плагина сотрудникам доступ к GitHub не нужен.

Если вы пользуетесь личным аккаунтом ChatGPT, для установки из готового архива воспользуйтесь [Codex на компьютере](#установка-из-архива-без-github).

### 1. Администратору — добавить плагин

**Из GitHub.** Войдите в GitHub под аккаунтом, которому открыт закрытый репозиторий `intergalactic-planb/plugins`. Этот же аккаунт используется при обновлении.

1. Откройте **Admin → Plugins → Add → Import marketplace**.
2. В **Source** укажите `https://github.com/intergalactic-planb/plugins`.
3. **Path** оставьте пустым.
4. В **Branch, tag, or commit** укажите `main`.
5. Нажмите **Import marketplace** и разрешите ChatGPT доступ к GitHub, когда он попросит. Проверьте результат в **Import results**. [Импорт из GitHub](https://learn.chatgpt.com/docs/enterprise/plugin-management)

**Из ZIP.** Если в консоли администратора есть **Plugins → Add → Upload plugin**, OpenAI позволяет загрузить плагин из файла. Загрузку нашего архива для Codex через эту кнопку пока не проверяли. [Загрузка ZIP в ChatGPT](https://help.openai.com/en/articles/20001256-plugins-in-chatgpt)

После добавления откройте карточку плагина. В **Installation policy** выберите **Available**, чтобы нужные сотрудники могли поставить его сами, или **Installed**, чтобы установить его для них. Этим же сотрудникам откройте приложение Quotalogic с доступом к данным.

### 2. Сотруднику — установить

1. В **Plugins** откройте вкладку с названием вашего рабочего пространства и выберите плагин Quotalogic со сценариями.
2. Нажмите **+**, если плагин ещё не установлен.
3. Если доступ к каталогам ещё не настроен, войдите в Quotalogic через приложение с доступом к данным.
4. Начните новый чат.

### 3. Проверить

Введите `@`, выберите Quotalogic со сценариями или `catalog-import` и приложите тестовый прайс. Попросите «Подготовь импорт этого прайса в новый каталог Quotalogic и покажи предпросмотр. Остановись до запуска импорта». На предпросмотре должны быть колонки и валюта. [Как выбрать плагин в ChatGPT](https://learn.chatgpt.com/docs/plugins#choose-a-specific-plugin)

Пометка **Desktop only** означает, что для этого плагина нужно открыть приложение на компьютере. Если Quotalogic отсутствует в меню `@` в новом чате, попросите администратора проверить доступ к плагину и к подключению Quotalogic.

### Обновить в ChatGPT web

- Каталог из GitHub проверяется раз в день. Чтобы обновить сразу, в **Admin → Plugins → Marketplaces** выберите каталог и нажмите **Sync now**. Проверьте в отчёте результат именно для Quotalogic. Если администратор потерял доступ к GitHub, восстановите доступ или поручите импорт другому администратору. [Обновление из GitHub](https://learn.chatgpt.com/docs/enterprise/plugin-management#keep-plugins-up-to-date)
- Для плагина, добавленного вручную из ZIP, откройте его карточку и выберите **Upload new version**, если эта кнопка доступна. [Обновление из ZIP](https://help.openai.com/en/articles/20001256-plugins-in-chatgpt)

После обновления начните новый чат.

### Удалить из ChatGPT web

Сотрудник удаляет `Quotalogic` в его карточке в разделе **Plugins**, если это разрешено правилами рабочего пространства. Администратор может сделать плагин недоступным для ролей. Если удалить сам каталог плагинов в **Admin → Plugins → Marketplaces**, пропадут все плагины, добавленные из него. Приложение Quotalogic с доступом к данным при этом остаётся и управляется отдельно.

## Если не работает

| Что видите                                               | Что делать                                                                                                                                                        |
| -------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ошибка доступа или `not found` при подключении из GitHub | Проверьте, что в терминале вы вошли под аккаунтом с доступом к репозиторию и выполнили `gh auth setup-git`. Можно также попросить готовый архив                   |
| Ошибка «путь не найден» при установке из архива          | Проверьте, что папка на месте и путь в команде верный                                                                                                             |
| Установка из архива просит доступ к GitHub               | Попросите у команды Quotalogic архив для установки без GitHub                                                                                                     |
| В списке после `$` нет `quotalogic`                      | Перезапустите приложение, выберите Codex и начните новый чат. В терминале можно проверить установку командой `codex plugin list --marketplace quotalogic-plugins` |
| Два одинаковых подключения в `codex mcp list`            | Удалите ручное: `codex mcp remove <имя>` (имя — из списка, не `quotalogic`)                                                                                    |
| Помощник говорит, что инструментов Quotalogic нет        | В Codex выполните `codex mcp login quotalogic`. В ChatGPT через браузер администратор может проверить, доступно ли оно вашему аккаунту                     |

## Для тех, кто собирает и тестирует

**Собрать архив** из клона `../plugins` (нужен доступ к репозиторию; берётся то, что закоммичено в `main`). Для Codex в архиве нужно подменить один файл: в самом репозитории маркетплейс Codex ведёт на GitHub, и без подмены установка из архива всё равно пойдёт в закрытый репозиторий. Проверено: с подменой плагин ставится из папки без GitHub, без неё Codex скачивает его с GitHub. Один архив подходит и для Codex, и для Claude.

```bash
T=$(mktemp -d) && cd "$T"
git -C ~/Projects/plugins archive --prefix=quotalogic-plugins/ main | tar -x
cat > quotalogic-plugins/.agents/plugins/marketplace.json <<'EOF'
{
  "name": "quotalogic-plugins",
  "interface": { "displayName": "Quotalogic Plugins" },
  "plugins": [
    {
      "name": "quotalogic",
      "source": { "source": "local", "path": "./" },
      "policy": { "installation": "AVAILABLE", "authentication": "ON_INSTALL" },
      "category": "Productivity"
    }
  ]
}
EOF
zip -qr ~/quotalogic-plugins.zip quotalogic-plugins
```

Версию плагина (в `.claude-plugin/plugin.json`) лучше указать в имени архива или в сообщении клиенту, чтобы было понятно, что он получил.

**Проверить сборку** — в чистой папке и с отдельными настройками Codex, чтобы не трогать свои:

```bash
mkdir -p ~/archive-test && cd ~/archive-test && unzip -q ~/quotalogic-plugins.zip
export CODEX_HOME=~/archive-test/codex-home && mkdir -p "$CODEX_HOME"
codex plugin marketplace add ~/archive-test/quotalogic-plugins
codex plugin add quotalogic@quotalogic-plugins
codex plugin list --marketplace quotalogic-plugins
```

В строке плагина в колонке `SOURCE` должен быть путь к папке, а не адрес GitHub.

**Известный баг бэкенда при проверке импорта.** Статуса `SUCCESS` недостаточно: бэкенд может сохранить дробную цену на цент меньше (`19.99` → `19.98`) без предупреждения. Для проверки самого плагина берите целую цену, например в таком файле:

```csv
SKU,Name,Price
WEB-05-1,Web Work Test,20
```

Чтобы испытать настоящий импорт в тестовом рабочем пространстве, попросите создать каталог `Web Work Test` в EUR, сопоставить `SKU` с артикулом, `Name` с названием, `Price` с основной ценой, показать таблицу и остановиться до отдельного «да». После «да» попросите перечитать товар и сверьте значения с файлом.
