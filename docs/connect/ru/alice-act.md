# Подключение Quotalogic к Алисе AI

[English](../en/alice-act.md) · **Русский** · [中文](../cn/alice-act.md)

Создайте личный плагин для тестового стенда Quotalogic в режиме **Действуй!**. Понадобятся учётная запись Quotalogic с доступом к тестовому рабочему пространству и **Алиса Плюс** с доступом к режиму **Действуй!**. Если видите кнопку **Получить ранний доступ**, нажмите её и проверьте, какие разрешения Яндекс запрашивает для Почты, Диска и Календаря, прежде чем подтвердить их. [Справка Яндекса](https://alice.yandex.ru/support/ru/assistant/chat/agent-act)

## Получить Client ID для Алисы

1. Откройте настройки воркспейса в Quotalogic и выберите **Агенты и доступ** (**Agents and access**).
2. Проверьте, что доступ агентов включён. Владелец или администратор воркспейса может включить его переключателем **Разрешить подключать агентов** (**Allow connecting agents**).
3. Под ссылкой **Как подключить плагин к агенту** (**How to connect the plugin to an agent**) нажмите **Получить Client ID для Алисы** (**Get Alice Client ID**) и скопируйте значение из поля. После обновления страницы в том же браузере последний ID можно снова скопировать из поля. Для каждого нового личного плагина нажимайте кнопку снова. Если отложили настройку и полученный Client ID истёк, получите новый.

## Создать плагин

1. Откройте Алису AI на [alice.yandex.ru](https://alice.yandex.ru/) и переключитесь в режим **Действуй!**.
2. В боковом меню откройте **Плагины** и нажмите **Создать плагин**.
3. Заполните форму.

   | Поле в Алисе | Значение |
   | --- | --- |
   | **Название** | `Quotalogic Staging` |
   | **Описание** | `Work with Quotalogic staging catalogs and proposals.` |
   | **Адрес MCP-сервера** | `https://mcp-staging.quotalogic.io/mcp` |

4. Откройте **Дополнительно** и заполните настройки подключения.

   | Поле в Алисе | Значение |
   | --- | --- |
   | **Протокол подключения** | `Streamable HTTP` |
   | **Способ авторизации** | **OAuth** |
   | **Авторизация OAuth-клиента** | **Без аутентификации** |
   | **Идентификатор клиента (Client ID)** | Client ID, который вы скопировали в Quotalogic |
   | **URL авторизации** | `https://mcp-staging.quotalogic.io/authorize` |
   | **URL получения токена** | `https://mcp-staging.quotalogic.io/token` |
   | **Области доступа (Scopes)** | Оставьте пустым |

5. Проверьте, что Алиса показывает адрес возврата `https://alice.yandex.ru/plugins/oauth/callback`, и нажмите **Создать**.

## Войти и проверить подключение

1. В карточке плагина нажмите **Подключить**. Проверьте запрашиваемые разрешения и подтвердите кнопкой **Подключить**.
2. Если Алиса покажет **Попробуйте войти через Яндекс Браузер**, нажмите **Продолжить как обычно**, чтобы открыть страницу входа в текущем браузере.
3. Войдите в Quotalogic, проверьте рабочее пространство на странице согласия и нажмите **Разрешить**.
4. После возврата в Алису в карточке появится отметка **Приложение подключено**. Нажмите **Попробовать** и спросите «Покажи мои каталоги через Quotalogic Staging». Алиса выведет каталоги вашего рабочего пространства. Чтобы увидеть, какой плагин вызвала Алиса, откройте **Работала** в задаче.
5. В разделе **Мои подключения** (**My connections**) появится **Алиса AI** (**Alice AI**). Повторный вход заменит ваше предыдущее подключение Алисы к этому воркспейсу.
