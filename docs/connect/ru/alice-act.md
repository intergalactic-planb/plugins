# Подключение Quotalogic к Алисе AI

[English](../en/alice-act.md) · **Русский** · [中文](../cn/alice-act.md)

Для обоих способов подключения нужна учётная запись Quotalogic с доступом к тестовому воркспейсу.

| Версия Алисы | Где настраивается | Как подключить Quotalogic |
| --- | --- | --- |
| **Алиса AI для бизнеса** | В кабинете Яндекс 360 администратор разрешает сотрудникам создавать плагины и навыки. | В режиме **Задачи** создайте личный MCP-плагин с Client ID и загрузите навыки отдельными ZIP. |
| **Алиса AI Про для бизнеса** | В Yandex Cloud администратор управляет профилями и рабочими местами сотрудников. | Загрузите один ZIP с MCP и навыками в **Плагины организации** и добавьте его в профиль рабочих мест. |

В личной Алисе AI используйте [личное подключение](#личный-mcp-плагин-и-отдельные-навыки) в режиме **Действуй!** с опцией **Алиса Плюс**.

## Личный MCP-плагин и отдельные навыки

### 1. Подготовьте Алису

#### Личная Алиса

1. Откройте [Алису AI](https://alice.yandex.ru/) и переключитесь в режим **Действуй!**. Для этого режима нужна опция **Алиса Плюс**.
2. Если видите кнопку **Получить ранний доступ**, нажмите её и проверьте разрешения, которые Яндекс запрашивает для Почты, Диска и Календаря, перед подтверждением. [Справка Яндекса](https://alice.yandex.ru/support/ru/assistant/chat/agent-act)

#### Алиса AI для бизнеса

1. **Администратор Яндекс 360** открывает кабинет организации → **Алиса AI для бизнеса → Настройки**. В блоке **Плагины** он включает **Создавать и редактировать плагины**.
2. **Сотрудник** открывает [Алису AI](https://alice.yandex.ru/), выбирает пространство организации и переключается в режим **Задачи**.

Для собственных навыков администратор отдельно включает **Навыки → Создавать и редактировать навыки**.

### 2. Получите Client ID в Quotalogic

1. Откройте настройки тестового воркспейса → **Агенты и доступ** (**Agents and access**).
2. Проверьте, что включена опция **Разрешить подключать агентов** (**Allow connecting agents**). Включить её может владелец или администратор воркспейса.
3. Под ссылкой **Как подключить плагин к агенту** (**How to connect the plugin to an agent**) нажмите **Получить Client ID для Алисы** (**Get Alice Client ID**) и скопируйте значение из поля.

### 3. Создайте личный плагин

1. В боковом меню Алисы откройте **Плагины**.

   - В режиме **Действуй!** нажмите **Создать плагин**.
   - В режиме **Задачи** нажмите **+** справа от поля поиска.

2. Заполните основные поля.

   | Поле в Алисе | Значение |
   | --- | --- |
   | **Название** | `Quotalogic Staging` |
   | **Описание** | `Work with Quotalogic staging catalogs and proposals.` |
   | **Адрес MCP-сервера** | `https://mcp-staging.quotalogic.io/mcp` |

3. Откройте **Дополнительно** и заполните настройки подключения.

   | Поле в Алисе | Значение |
   | --- | --- |
   | **Протокол подключения** | `Streamable HTTP` |
   | **Способ авторизации** | **OAuth** |
   | **Авторизация OAuth-клиента** | **Без аутентификации** |
   | **Идентификатор клиента (Client ID)** | Client ID, который вы скопировали в Quotalogic |
   | **URL авторизации** | `https://mcp-staging.quotalogic.io/authorize` |
   | **URL получения токена** | `https://mcp-staging.quotalogic.io/token` |
   | **Области доступа (Scopes)** | Оставьте пустым |

4. Сверьте адрес возврата `https://alice.yandex.ru/plugins/oauth/callback` и нажмите **Создать**.

> **В рабочей Алисе оставьте плагин личным.** Каждый сотрудник создаёт свой плагин, получает свой Client ID и сам входит в Quotalogic. Если общий плагин использует подключение автора, запросы коллег выполняются от его имени и с его правами в воркспейсе, который он подтвердил при входе.

### 4. Подключите плагин и проверьте работу

1. В карточке плагина нажмите **Подключить**, проверьте разрешения и подтвердите подключение.

   Если Алиса покажет **Попробуйте войти через Яндекс Браузер**, нажмите **Продолжить как обычно**.

2. Войдите в Quotalogic, убедитесь, что на странице согласия указан тестовый воркспейс, и нажмите **Разрешить**.
3. Дождитесь отметки **Приложение подключено** в карточке Алисы. Нажмите **Попробовать** и спросите «Покажи мои каталоги через Quotalogic Staging». Алиса выведет каталоги выбранного воркспейса. В разделе **Работала** можно увидеть вызов плагина.
4. В Quotalogic проверьте, что в разделе **Агенты и доступ → Мои подключения** (**My connections**) появилась **Алиса AI** (**Alice AI**).

### 5. Загрузите навыки

1. Скачайте [репозиторий Quotalogic](https://github.com/intergalactic-planb/plugins) через **Code → Download ZIP** и распакуйте архив.
2. В папке `skills/` выберите нужный навык. Упакуйте его папку в отдельный ZIP вместе с `SKILL.md` и другими файлами навыка. Повторите для каждого нужного навыка.
3. В Алисе откройте **Плагины → Навыки**, нажмите **+** и загрузите ZIP навыка.

### Client ID и повторный вход

#### Где повторно скопировать Client ID

В том же браузере последний выданный ID остаётся в поле в настройках воркспейса после обновления страницы.

#### Что происходит при выдаче нового Client ID

Получайте новый ID для каждого нового плагина. Прежний ID остаётся зарегистрированным, а уже подключённый плагин продолжает работать. Quotalogic отзывает предыдущее подключение Алисы, когда вы подтверждаете новое под тем же аккаунтом в том же воркспейсе.

#### Сколько действует Client ID

После подключения Client ID бессрочный и сохраняется даже после отзыва подключения. Фоновая очистка может удалить ID спустя сутки после выдачи, если по нему нет ни подключения, ни незавершённого входа. Если ID истёк, получите новый.

#### Как войти в Quotalogic повторно

Если доступ отозвали в Quotalogic, а на карточке осталось **Приложение подключено**, нажмите **⋯ → Отключить**, затем **Подключить**. На странице Quotalogic проверьте воркспейс и нажмите **Разрешить**.

Если Алиса попросит войти снова, используйте тот же Client ID. Токен доступа действует 1 час, токен обновления — 30 дней с момента выдачи. При каждом успешном обновлении Алиса получает новую пару токенов с теми же сроками.

## Общий ZIP в Алисе AI Про для бизнеса

### 1. Подготовьте ZIP

1. Скачайте [репозиторий Quotalogic](https://github.com/intergalactic-planb/plugins) через **Code → Download ZIP** и распакуйте архив.
2. Поместите квадратную PNG-иконку плагина в `assets/quotalogic-icon.png`. В `.codex-plugin/plugin.json` сохраните название и описание, удалите поле `skills` и задайте для `interface.logo` и `interface.composerIcon` путь `assets/quotalogic-icon.png`.
3. Соберите ZIP с такой структурой в корне. Максимальный размер файла — 64 МБ. [Формат архива Яндекса](https://aistudio.yandex.ru/ru/docs/ai-studio/manage/operations/add-organization-plugin)

```text
.codex-plugin/plugin.json
.mcp.json
skills/
assets/quotalogic-icon.png
```

### 2. Добавьте плагин и назначьте профиль

1. С ролью `ai.workProfiles.admin` откройте [Управление в Yandex Cloud](https://aistudio.yandex.ru/manage). В разделе **Плагины организации → Добавить плагин** укажите название **Quotalogic Staging**, выберите ZIP и нажмите **Добавить**.
2. В разделе **Профили** откройте нужный профиль. Добавьте пакет в блоке **Плагины → Плагины организации** и сохраните профиль.
3. В разделе **Рабочие места** выдайте сотруднику место с этим профилем или назначьте профиль уже выданному месту. Для работы сотруднику нужны подписка **Алиса AI Про для бизнеса** и рабочее место. [Рабочие места](https://aistudio.yandex.ru/ru/docs/ai-studio/manage/operations/manage-runtimes)

### 3. Проверьте доступ с рабочего места

1. Откройте [Алису AI Про для бизнеса](https://aistudio.yandex.ru/agents) под аккаунтом сотрудника и выберите рабочее место с назначенным профилем.
2. Если Алиса предложит подключить Quotalogic, войдите под своим аккаунтом Quotalogic, проверьте тестовый воркспейс и подтвердите доступ.
3. Попросите Алису показать каталоги через **Quotalogic Staging** и проверьте, что в ответе каталоги выбранного воркспейса.
